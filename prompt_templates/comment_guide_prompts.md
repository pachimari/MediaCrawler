# 评论引导话术生成Prompt模板

## 核心原则

1. **软性引导**: 不直接留联系方式,通过价值触发对方主动
2. **角色扮演**: 根据账号人设生成差异化话术
3. **自然对话**: 避免营销感,像真实用户互动

---

## Prompt 1: 用户意向评分

```
你是旅游意向分析专家。分析以下评论,输出JSON格式:

评论内容: {comment_text}
用户昵称: {nickname}
用户主页信息: {user_bio}
视频主题: {video_topic}

评估维度:
1. 目的地明确度(0-30分): 是否提到具体地点
2. 出行时间紧迫度(0-25分): 近期/下月/暑假/没说
3. 预算透露度(0-20分): 是否讨论价格
4. 决策权(0-15分): "我想去"vs"我们想去"vs"求推荐"
5. 竞争度(0-10分): 有多少人同时回复这条评论

输出格式:
{
  "总分": 85,
  "目的地": "云南大理",
  "出行时间": "5月中旬",
  "预算范围": "3000-5000",
  "用户画像": "25-30岁女性,独自旅行,文艺风格",
  "建议策略": "A类高优,24小时内回复",
  "竞争情况": "已有2人回复,需差异化"
}
```

## Prompt 2: 角色化话术生成

```
角色设定: {role_persona}
目标用户: {user_profile}
视频内容: {video_summary}
用户评论: {original_comment}

生成3条递进式回复话术,要求:

【规则】
1. 禁止直接留微信/电话/公众号
2. 必须符合角色人设(旅游达人/当地土著/刚去过的游客)
3. 每条话术有不同切入点
4. 50字以内,口语化
5. 设置"钩子"让对方主动私信

【话术1 - 共鸣引导型】
策略: 先认同对方,再抛出诱饵
示例: "姐妹我上个月刚去的大理!古城真的巨美😍 我有份避雷攻略,需要的话可以私我~"

【话术2 - 价值提供型】  
策略: 展示独家资源,但不直接给
示例: "巧了,我表哥在丽江开客栈,经常有内部折扣票,你们几个人去呀?"

【话术3 - 制造稀缺型】
策略: 限时/限量,催化行动
示例: "5月大理客栈超难订!我之前住的那家老板娘人超好,要不要我帮你问问还有房?"

---

输出格式(JSON):
{
  "话术1": "...",
  "话术1_触发点": "避雷攻略",
  "话术2": "...",  
  "话术2_触发点": "内部折扣",
  "话术3": "...",
  "话术3_触发点": "稀缺房源",
  "推荐使用": "话术2",
  "原因": "用户评论提到预算,价格敏感"
}
```

## Prompt 3: 多变体生成(避免重复检测)

```
基础话术: {base_comment}
目标: 生成10个语义相同但表达不同的变体

要求:
1. 改变句式结构(陈述句/疑问句/感叹句)
2. 替换同义词(超好→巨赞→yyds→绝了)
3. 调整标点和emoji
4. 控制相似度<60%

示例:
原始: "我上个月刚去的大理,有避雷攻略需要吗?"

变体1: "大理刚去过!踩了好多坑😂 有需要攻略的嘛~"
变体2: "巧了,五月初在大理待了一周,要不要分享下经验?"
变体3: "姐妹!大理我熟啊哈哈,有啥想问的随时🙋‍♀️"
变体4: "上个月大理游记还没发完😅 你们准备去多久呀?"
变体5: "emmm大理我去过3次了算半个地头蛇,需要帮助尽管说~"
...

输出JSON数组格式
```

  "风险等级": "低", // 低/中/高
  "问题点": [],

## 6. 发布策略

### 时间分布

- 避免集中发布: 每个视频间隔2-4小时
- 最佳时段: 12:00-14:00, 19:00-22:00(用户活跃期)
- 随机延迟: +- 15分钟波动

### 频率控制  

- 每个账号: 最多5条/天
- 每个视频: 最多1条评论/账号
- 同一用户: 72小时内不重复评论

## 8. 异常处理

### 场景1: 评论被删除

- 原因分析: 营销意图过强/被举报
- 应对: 标记该视频作者风格,调整话术

### 场景2: 账号被限流

- 现象: 评论不显示/只有自己可见
- 应对: 暂停该账号24小时,切换备用账号

### 场景3: 用户未回复

- 等待48小时后发送第二条评论
- 使用不同角色/不同话术
- 最多尝试2次,避免骚扰

### 场景4: 竞争对手回复

- 监控其他回复内容
- 差异化定位(他们做价格,你做服务)
- 必要时放弃该用户(ROI过低)
